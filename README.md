# Proppant

Исследовательский код расчёта давления и переноса проппанта в двумерной сетке. Историческая реализация использовала Qt интерфейс и метод прогонки для решения трёхдиагональной системы на каждом шаге.

## Запускаемый пример

`examples/pressure_demo.cpp` изолирует метод прогонки на простой проверяемой задаче: стационарное одномерное давление при постоянной проводимости и заданных давлениях на границах. Точное решение линейно, поэтому программа вычисляет максимальную ошибку и завершится с ошибкой при расхождении.

```bash
g++ -std=c++17 -Wall -Wextra -Werror -O2 examples/pressure_demo.cpp -o pressure_demo
./pressure_demo 21 pressure.csv
```

CSV содержит номер узла и давление. Для этого примера не нужны Qt, внешние библиотеки или промысловые данные. GitHub Actions компилирует и выполняет его после каждого изменения.

## Историческая реализация

`legacy_qt_fragment.cpp` — сохранившийся фрагмент обработчика Qt с двумерной сеткой, граничными условиями, коэффициентами фильтрации и переносом проппанта. В публикации нет формы интерфейса, класса окна и полного проекта Qt, поэтому этот файл **не компилируется самостоятельно**. Пример выше демонстрирует только численный метод, а не воспроизводит физику и результаты всего расчёта проппанта.
